# Hi, I'm Kaikai Cao 👋

I'm a graduate student interested in **Cryptography, Zero-Knowledge Proofs, and AI Agent Security**.

My work focuses on exploring practical security problems and building reproducible prototypes to evaluate potential solutions.

## Research Interests

- **Zero-Knowledge Proofs:** SNARKs, Halo2, circuit design, and proof-system engineering.
- **AI Agent Security:** Authorization, execution integrity, and tool-use security.
- **Cryptographic Trust Mechanisms:** Identity and context binding, replay prevention, and verifiable audit trails.
- **Privacy-Preserving Systems:** Exploring how cryptographic techniques can support secure and privacy-aware applications.
